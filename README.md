# Hyperlocal Skills Exchange Platform

A community marketplace where users exchange skills and services instead of money.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB
- Real-time chat: Socket.io
- Authentication: JWT + bcrypt
- Styling: Tailwind CSS (to be configured)

## Project Structure

- `frontend/` — React client
- `backend/` — Express API and Socket.io server
- `database/` — database notes/seeds
- `docs/` — architecture and API documentation

## Development
Backend and frontend will be implemented incrementally.
